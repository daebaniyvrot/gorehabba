# Гарехабба 💩🛺

[![CI](https://github.com/daebaniyvrot/gorehabba/actions/workflows/ci.yml/badge.svg)](https://github.com/daebaniyvrot/gorehabba/actions/workflows/ci.yml)

Мультиплеерная 3D-браузерная игра про фестиваль кидания коровьими лепёшками —
по мотивам настоящего фестиваля [Gorehabba](https://en.wikipedia.org/wiki/Gorehabba)
(деревня Гуматапура, Карнатака, Индия), где попадание лепёшкой — к удаче.

**Играть:** https://v1nce.me/fest/ — работает на десктопе и телефоне (тач-управление включается само).

## Что внутри

- Бросание лепёшек с честной баллистикой (дуги, отскоки, шлепки-декали) и крик «СААР!» (Q)
- 22 жителя-NPC: кидаются, уворачиваются, смеются, если в вас попали
- Магазин: шлёпанцы (+скорость), зонтик (щит), маска от запаха, стирка
- Свой ларёк «НАВОЗ СААРА»: торг с покупателями и торговые битвы с конкурентом
- Безумный тук-тук: виляет, сигналит каждую секунду, громко играет музыка
- 8 квестов, фоторежим с оценкой кадра, двойной прыжок с сальто
- Мультиплеер: общий мир, игроки видят друг друга, кидаются и кричат вместе
- Сохранение в localStorage, автосейв

## Технологии

Three.js r160 (вендорен в `vendor/`), чистые ES-модули без сборки, весь UI на русском.
Сервер — Node 20+ и единственная зависимость `ws`: раздаёт статику и WebSocket-релей
мультиплеера (`/ws`). Звук — синтез WebAudio, геометрия — процедурный low-poly.

## Запуск

```bash
npm ci --omit=dev
node server/server.js          # http://localhost:8137
```

Или в Docker:

```bash
docker compose up -d --build   # см. DEPLOY.md
```

## Релизы

Релизы собираются вручную экшеном «Релиз» (Actions → Релиз → Run workflow, версия
вида `1.1.0` без `v`): прогоняются тесты и прод-репетиция, мультиарх-образ уезжает в
`ghcr.io/daebaniyvrot/gorehabba` (`:{версия}` и `:latest`), создаются git-тег `v{версия}`
и GitHub Release. Деплой из готового образа — в [DEPLOY.md](DEPLOY.md).

## Управление

WASD — бег · Space — прыжок (двойной!) · ЛКМ — замах/бросок · ПКМ — зонтик ·
Q — «СААР!» · E — взаимодействие · P — фоторежим · Tab — квесты.
На телефоне: джойстик слева, камера свайпом справа, кнопки действий.
